# BP — Bismaya Purchase

BNCP(Bismayah New City Project) 현장 구매내역(2015~)을 조회·분석하는 웹 도구입니다. GitHub Pages에서 정적 페이지로 동작합니다.

## 기능

| 화면 | 내용 |
|---|---|
| 통합 검색 | 품명·규격·자재코드·**한글 품명** 검색, 자동완성, 오타 보정 → 단가 추이(환율 변경·주요 사건 표시), 규격별·거래처별 단가, 발주 내역. 즐겨찾기·최근 검색, 품목 링크 복사 |
| 거래처 | 업체별 거래 기간·금액·비중, 연도별 발주액, 주요 품목 |
| 견적 체크 | 여러 업체 견적서(사진·PDF·엑셀) 또는 **업체를 나란히 둔 가격비교표(Price Comparison) 엑셀**을 올리면 품목별 **업체 견적 비교표** 작성. 최근 실제 구매 업체·단가·일자와 견적별 변동 %, 최저가 표시. 엑셀로 저장 |
| 반복 구매 | 반복 구매 품목, 최근 12개월 소요량, 발주 간격, 연간 예상 금액, **내년 예산 시뮬레이션** |
| 단가 동향 | 직전 구매 대비 원 변동 / 같은 구간 시장 변동(코로나·호르무즈 전후 구분) / 시장 반영 후 변동, 비교 신뢰도 A·B·C, 2026-10-07 환율 변경 영향 |
| 지출 현황 | 현장·부서별, 품목군별, 연도별 발주액 |
| 데이터 갱신 | 구매내역 엑셀 → 브라우저에서 암호화한 `data.enc` 생성 (Python 불필요) |

- 모든 표는 머리글을 누르면 정렬됩니다.
- 상단에서 화면 언어(한국어/English)와 기준 통화(IQD/USD)를 바꿀 수 있습니다.
- 데이터 기준일이 45일 이상 지나면 상단에 "갱신 필요"가 표시됩니다.
- 한글 품명은 `lib/ko_dict.json`(원본: `tools/ko_words_*.txt`, `tools/ko_phrases.txt`)으로 만듭니다. 번역을 고치려면 txt를 고치고 JSON을 다시 만드세요.
- 영어 화면 문구는 `lib/i18n_en.js`에 있습니다.

## 견적서 인식

- 가격비교표 엑셀: 업체별 Unit Price 열을 각각 읽습니다. **Item Code(자재코드) 열**이 있으면 코드로 정확히 매칭하고, 없으면 품명+규격으로 매칭합니다. 표 위쪽의 Date를 읽어 **비교 기준일**(그 날짜 이전 구매만 비교)을 자동 입력합니다.

- 엑셀: 머리글(Description / Unit Price / Qty / Unit 등, 아랍어 머리글 일부 포함)을 찾아 열을 읽습니다.
- PDF: 글자가 들어 있는 PDF는 텍스트를 그대로 읽고, 스캔 PDF는 이미지로 바꿔 OCR 합니다.
- 사진: 브라우저 안에서 OCR(Tesseract) 합니다. 확대·조명 보정·표 테두리 제거 후 인식합니다.
- 모든 처리는 브라우저 안에서만 이뤄지고 파일은 서버로 보내지지 않습니다.
- 라이브러리는 `lib/` 폴더에 들어 있습니다 (tesseract.js 5.1.1, pdf.js 3.11.174, SheetJS 0.18.5, 영어·아랍어 인식 데이터).

## 데이터 보안

- 저장소에는 **암호화된 `data.enc`만** 올립니다. 원본 엑셀은 올리지 않습니다 (`.gitignore`).
- `data.enc`는 AES-256-GCM으로 암호화되고, 키는 비밀번호에서 PBKDF2-SHA256(250,000회)으로 만듭니다.
- 비밀번호는 브라우저 안에서만 쓰이고 어디로도 전송되지 않습니다.
- 비밀번호가 약하면 암호문을 추측 공격할 수 있으니 12자 이상을 권장합니다.

## 데이터 갱신 / 비밀번호 변경

가장 쉬운 방법은 화면 오른쪽 위 **데이터 갱신** 메뉴입니다.

- **올린 연도만 교체 (기본)**: 바꿀 연도 파일만 올리면 그 연도만 새 자료로 바뀌고 나머지 연도는 그대로 유지됩니다. 예: 2026년 파일 하나만 올려 2026년 갱신.
- **전체 새로 만들기**: 올린 파일만으로 데이터를 새로 만듭니다. 2015년부터 전체 연도 파일이 필요합니다.

아래 스크립트는 전체 새로 만들기를 PC에서 하는 방법입니다.


```bash
pip install pandas xlrd cryptography
python tools/build_data.py --src <구매내역 xls 폴더> --password <비밀번호>
git add data.enc && git commit -m "data: 구매내역 갱신" && git push
```

회사 시스템의 "구매내역(자재 기준)" 연도별 엑셀을 한 폴더에 넣고 실행합니다. 소계 행은 자동 제외됩니다.

## 참고

- 기본 표시 통화는 IQD이고, 화면 상단에서 USD로 바꿀 수 있습니다.
- 다른 통화로 산 건은 **발주 당시 환율**로 환산합니다. 과거 단가를 현재 환율로 다시 환산하지 않습니다.
- 환율표는 `app.js`의 `FX`에 있습니다 (회사 시스템 연도별 환율 + 2026-10-07 CBI 1,520).
- 2026-10-07 이후 IQD 발주는 회사 시스템이 1,320으로 환산해도 BP는 1,520으로 USD를 다시 계산합니다 (`FX_FIX_FROM`).
- 단가 동향은 환율 영향을 빼기 위해 USD 기준으로 계산합니다. 비교 신뢰도 규칙은 `app.js`의 `gradeOf`에 있습니다.
- 품목군은 자재코드 앞 두 자리 기준의 추정 분류입니다 (`app.js`의 `CAT`).
- SAB Airfield 현장은 현장명에 "SAB"가 들어간 경우로 구분합니다.
