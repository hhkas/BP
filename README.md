# BP — Bismaya Purchase

BNCP(Bismayah New City Project) 현장 구매내역(2015~)을 조회·분석하는 웹 도구입니다. GitHub Pages에서 정적 페이지로 동작합니다.

## 기능

| 화면 | 내용 |
|---|---|
| 통합 검색 | 품명·규격·자재코드 검색 → 단가 추이, 규격별·거래처별 단가, 발주 내역 |
| 거래처 | 업체별 거래 기간·금액·비중, 연도별 발주액, 주요 품목 |
| 견적 체크 | 견적 품목·단가를 붙여넣으면 과거 이력(최저·중앙·최고·최근) 안에서의 위치 표시 |
| 반복 구매 | 여러 해 반복 구매 품목, 최근 12개월 소요량, 발주 간격, 연간 예상 금액 |
| 지출 현황 | 현장·부서별, 품목군별, 연도별 발주액 |
| 고가 구매 리포트 | 초기 구매 단가가 이후 중앙단가보다 높았던 품목을 업체별로 집계 |

## 데이터 보안

- 저장소에는 **암호화된 `data.enc`만** 올립니다. 원본 엑셀은 올리지 않습니다 (`.gitignore`).
- `data.enc`는 AES-256-GCM으로 암호화되고, 키는 비밀번호에서 PBKDF2-SHA256(250,000회)으로 만듭니다.
- 비밀번호는 브라우저 안에서만 쓰이고 어디로도 전송되지 않습니다.
- 비밀번호가 약하면 암호문을 추측 공격할 수 있으니 12자 이상을 권장합니다.

## 데이터 갱신 / 비밀번호 변경

```bash
pip install pandas xlrd cryptography
python tools/build_data.py --src <구매내역 xls 폴더> --password <비밀번호>
git add data.enc && git commit -m "data: 구매내역 갱신" && git push
```

회사 시스템의 "구매내역(자재 기준)" 연도별 엑셀을 한 폴더에 넣고 실행합니다. 소계 행은 자동 제외됩니다.

## 참고

- 기본 표시 통화는 IQD이고, 화면 상단에서 USD로 바꿀 수 있습니다.
- 다른 통화로 산 건은 **발주 당시 환율**로 환산합니다. 과거 단가를 현재 환율로 다시 환산하지 않습니다.
- 환율표는 `app.js`의 `FX`에 있습니다 (회사 시스템 연도별 환율 + 2026-10-07 CBI 1,520).
- 2026-10-07 이후 IQD 발주는 회사 시스템이 1,320으로 환산해도 BP는 1,520으로 USD를 다시 계산합니다 (`FX_FIX_FROM`).
- 고가 구매 리포트는 장기 비교라서 항상 USD 기준으로 계산합니다.
- 품목군은 자재코드 앞 두 자리 기준의 추정 분류입니다 (`app.js`의 `CAT`).
- SAB Airfield 현장은 현장명에 "SAB"가 들어간 경우로 구분합니다.
